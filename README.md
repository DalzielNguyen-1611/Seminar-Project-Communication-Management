# 🚀 Seminar: Project Communication Management (PCM) Evolution

Dự án này là một ứng dụng thuyết trình tương tác (Interactive Slide Deck) về chủ đề **Quản lý Truyền thông Dự án**, tập trung vào sự tiến hóa của các tiêu chuẩn quản trị dự án hiện đại.

---

## 📝 1. Nội dung Seminar

Slide deck này phân tích sự dịch chuyển tư duy truyền thông qua các phiên bản tiêu chuẩn toàn cầu:

*   **PMBOK® 6:** Kỷ nguyên "Đóng gói" theo Quy trình (Process-based). Tập trung vào sản phẩm đầu ra và các luồng thông tin hành chính.
*   **PMBOK® 7:** Kỷ nguyên "Hòa tan" vào Nguyên tắc (Principles-based). Đề cao giá trị mang lại, sự thấu cảm và các kỹ năng quyền lực (Power Skills).
*   **PMBOK® 8:** Kỷ nguyên "Tích hợp Thực tiễn" (Pragmatic Integration). Kết hợp hoàn hảo giữa quy trình chuẩn mực, trí tuệ cảm xúc của con người và sức mạnh của AI.

### Trụ cột truyền thông tương lai:
1.  **Technology-enabled:** AI xử lý dữ liệu, tự động hóa báo cáo và phân tích cảm xúc (NLP).
2.  **Human-led:** Con người dẫn dắt bằng sự thấu cảm và niềm tin.
3.  **Principle-driven:** Giao tiếp linh hoạt, đồng sáng tạo và minh bạch quyết liệt.

## 🛠️ 2. Hướng dẫn cài đặt và Khởi chạy

Để chạy slide trên máy tính cá nhân, vui lòng thực hiện các lệnh sau:

### Bước 1: Clone dự án
```bash
git clone https://github.com/DalzielNguyen-1611/Seminar-Project-Communication-Management.git
```

### Bước 2: Cài đặt thư viện (Dependencies)
```bash
cd Seminar-Project-Communication-Management
npm install
```

### Bước 3: Khởi chạy môi trường phát triển
```bash
npm run dev
```
*Mặc định, slide sẽ hiển thị tại: `http://localhost:5173`.*
